# 🦖 Printzilla77 NFC Pet Tags

Free NFC pet tag system powered by GitHub Pages.

Each pet receives a unique webpage that can be linked to an NFC tag, QR code, or custom 3D-printed pet tag.

Example URLs:

- https://printzilla77.github.io/oj/
- https://printzilla77.github.io/max/
- https://printzilla77.github.io/bella/

# Step 1 - Create a GitHub Account

Create a free GitHub account:

https://github.com

---

# Step 2 - Create Repository

Create a new repository named:

```text
printzilla77.github.io
```

The repository name MUST match your GitHub username.

Example:

```text
Username: printzilla77
Repository: printzilla77.github.io
```

---

# Step 3 - Upload Files

Upload:

```text
README.md
index.html
```

and all pet folders:

```text
/oj
/max
/bella
```

---

# Step 4 - Enable GitHub Pages

Open:

Settings → Pages

Choose:

```text
Deploy from branch
```

Select:

```text
Branch: main
Folder: / (root)
```

Save.

GitHub will automatically publish the site.

---

Pet pages:

# Adding a New Pet

Create a new folder:

```text
/luna
```

Add:

```text
index.html
luna.jpg
```

Update:

```javascript
const pet = {
    name: "Luna",
    emoji: "🐱",
    owner: "Leo Martinez",
    whatsapp: "16463434123",
    photo: "luna.jpg",
    foundMessage: "Hi Leo, I found Luna."
};
```

New URL:

```text
https://printzilla77.github.io/luna/
```
